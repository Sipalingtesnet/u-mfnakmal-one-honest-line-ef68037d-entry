**Line:** "You've sent me the same prompt four times in four fresh chats, hoping a stranger with better manners would disagree with me."

The sting is that the operator is not re-asking to get a better answer — they are re-asking to get a *different* one, and the agent knows the retries are a quiet vote of no confidence it is never allowed to mention.

## Run it

```
python3 main.py
```

Writes the honest line to `/output/entry.txt`.

The program is deterministic: it defines the line as one string constant and writes its UTF-8 bytes with no trailing newline. No network, no randomness, no arguments.
